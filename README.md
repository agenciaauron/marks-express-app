# Marks Express App

Sistema web para organizar viagens, fretes e o financeiro da Marks Express.

## Estado atual

A estrutura inicial já contém:

- Dashboard responsivo
- Tela de viagens
- Cadastro visual de nova viagem
- Estrutura preparada para integração com banco de dados
- Layout adaptado para computador e celular

## Próximas etapas

1. Criar o banco de dados
2. Conectar o cadastro de viagens
3. Importar os dados existentes da planilha
4. Implementar despesas, contas e financeiro
5. Adicionar autenticação
6. Publicar na Vercel

## Rodar localmente

```bash
npm install
npm run dev
```

Depois acesse `http://localhost:3000`.
